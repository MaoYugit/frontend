### 一、 项目框架构建（pnpm + TypeScript）

在终端执行以下命令，初始化 Vue 3 官方推荐的项目模板：

```bash
# 1. 启动安装向导
pnpm create vue@latest

# 2. 配置选项选择 (请按如下提示选择)
# √ Project name: ... vue3-study
# √ Add TypeScript? ... Yes
# √ Add JSX Support? ... No
# √ Add Vue Router? ... No (本阶段暂不添加，后续板块手动集成)
# √ Add Pinia? ... No
# √ Add Vitest? ... No
# √ Add ESLint? ... Yes
# √ Add Prettier? ... Yes

# 3. 进入目录并安装依赖
cd vue3-study
pnpm install

# 4. 启动开发服务器
pnpm dev
```

**项目核心文件结构：**
*   `src/App.vue`：根组件。
*   `main.ts`：项目入口，负责创建应用实例。
*   `env.d.ts`：让 TS 识别 `.vue` 文件。
*   `tsconfig.json`：TypeScript 配置文件。

### 二、 1.2 `<script setup>` 语法糖

`<script setup>` 是在单文件组件 (SFC) 中使用 Composition API 的编译时语法糖。

#### 1. 核心特性：自动暴露
在传统的 `setup()` 函数中，所有变量和方法必须通过 `return {}` 暴露。而在 `<script setup>` 中：
*   **顶层绑定自动暴露**：在 `<script setup>` 顶层声明的变量、函数、甚至 `import` 进来的组件/工具，都可以在 `<template>` 中直接使用。

#### 2. 代码对比（面试常考：为什么用 setup 语法糖？）

**旧版（Composition API 原始写法）：**
```vue
<script lang="ts">
import { ref } from 'vue'
export default {
  setup() {
    const count = ref(0)
    const increment = () => count.value++
    return { count, increment } // 必须手动返回，极其繁琐
  }
}
</script>
```

**新版（`<script setup>`）：**
```vue
<script setup lang="ts">
import { ref } from 'vue'

// 1. 响应式变量直接声明
const count = ref(0)

// 2. 方法直接声明
const increment = () => {
  count.value++
}
</script>

<template>
  <!-- 3. 模板中直接使用，无需 return -->
  <button @click="increment">Count is: {{ count }}</button>
</template>
```

#### 3. TypeScript 的深度集成
由于使用了 `lang="ts"`，`<script setup>` 提供了更强的类型支持。

*   **变量类型推导**：
    ```ts
    const msg = ref<string>('Hello Vue 3') // 显式声明
    const isShow = ref(false)              // 自动推导为 boolean
    ```
*   **函数参数与返回值约束**：
    ```ts
    const sum = (a: number, b: number): number => {
      return a + b
    }
    ```

#### 4. 组件自动注册
在 `<script setup>` 中，引入的组件无需在 `components` 选项中注册，直接在模板中使用：

```vue
<script setup lang="ts">
import MyComponent from './components/MyComponent.vue'
</script>

<template>
  <MyComponent />
</template>
```

### 三、 实际开发细节

1.  **执行时机**：`<script setup>` 中的代码在**每次组件实例创建时执行**。
2.  **唯一性**：一个 `.vue` 文件最多只能有一个 `<script setup>`（但可以额外包含一个普通的 `<script>` 用于导出插件配置等特殊需求）。
3.  **配合插件**：必须安装前文提到的 `Vue - Official` 插件，否则编辑器无法识别顶层绑定，会报“变量已定义但未使用”的错误。
