# Vue 3 学习大纲 

## 板块一：开发准备与 Vue 3 核心基础 (Composition API)

*   **1.1 开发环境搭建与必备工具**
    *   **编辑器环境**：VS Code 安装及官方推荐插件（`Volar / Vue - Official`, `ESLint`, `Prettier`）配置
    *   **调试利器**：Chrome/Edge 浏览器 `Vue Devtools` 插件的安装与响应式数据追踪、组件树排查方法
    *   **💡 TypeScript 学习策略说明**
        *   *若已有 TS 基础*：可直接开启 TS 模式进入后续学习。
        *   *若无 TS 基础*：前4个板块建议采用 JS 模式（或最基础的 TS 声明），将重心放在 Vue 响应式原理与路由、状态上，到板块五再系统补充并重构。
*   **1.2 `<script setup>` 语法糖**
    *   响应式变量、方法的直接暴露与模板使用
*   **1.3 响应式核心 API**
    *   `ref`（基本类型与对象响应式、`.value` 访问与局限性）
    *   `reactive`（深层响应式对象与数组、重新赋值响应式丢失问题及规避方案）
*   **1.4 响应式进阶 API**
    *   `toRef` 与 `toRefs`（响应式对象解构）
    *   `shallowRef` 与 `shallowReactive`（浅层响应式，大型数据集性能优化）
    *   `readonly` 与 `shallowReadonly`（只读代理与数据保护）
*   **1.5 计算属性与侦听器**
    *   `computed`（只读计算属性、可写计算属性）
    *   `watch`（精确监听、深度监听、立即监听、停止监听、`flush` 配置项、侦听器随组件销毁自动注销的机制）
    *   `watchEffect`（自动依赖收集、副作用清除、执行时机配置）
*   **1.6 基础指令、属性绑定与渲染控制**
    *   常用指令（`v-if`, `v-for`, `v-show`, `v-bind`, `v-on`）
    *   动态 CSS、class、style 绑定与现代 CSS 方案基础
    *   **性能辅助指令**（`v-once` 静态内容标记、`v-memo` 缓存模板片段减少重复渲染）
*   **1.7 组合式生命周期钩子**
    *   挂载阶段（`onMounted`、`onBeforeMount`）
    *   更新阶段（`onUpdated`、`onBeforeUpdate`）
    *   卸载阶段（`onUnmounted`、`onBeforeUnmount`）
    *   调试钩子（`onRenderTracked`、`onRenderTriggered`）

## 板块二：组件通信与交互逻辑 (Component Communication)

*   **2.1 父传子：Props 机制**
    *   `defineProps` 的运行时声明（以及可选的 TypeScript 类型声明）
    *   单向数据流原则与 Props 的默认值配置
    *   **响应式 Props 解构**（**Vue 3.5+ 推荐**，解构后保留响应式并支持默认值声明）
*   **2.2 子传父：Emits 机制**
    *   `defineEmits` 的声明方式
    *   `emit` 触发自定义事件与传参
*   **2.3 双向绑定：`v-model` 机制**
    *   `defineModel`（**Vue 3.4+ 推荐**双向绑定方案）
    *   单/多 `v-model` 绑定与自定义修饰符
*   **2.4 跨级组件通信：Provide / Inject**
    *   `provide` 数据的非响应式与响应式传递（配合 `ref`/`reactive`）
    *   `inject` 数据的获取、默认值设置与只读保护（配合 `readonly` 确保数据单向修改）
*   **2.5 实例与方法暴露：Ref + `defineExpose`**
    *   **`useTemplateRef`**（**Vue 3.5+ 推荐**，更具类型安全的模板引用方式）
    *   `defineExpose` 显式向外公开属性与方法（控制组件的封装边界）
*   **2.6 透传属性与事件：Attrs**
    *   `useAttrs` 获取未被声明为 Props/Emits 的属性和事件
    *   `inheritAttrs: false` 禁用默认透传行为与手动绑定
*   **2.7 全局事件总线（替代方案）**
    *   第三方库（如 `mitt`）在 Vue 3 中的集成与使用
*   🚩 **【阶段实战里程碑一：高交互组件应用】**
    *   **项目建议**：多功能待办清单（Todo List）或简易看板系统（Kanban Board）。
    *   **练习核心**：组件的深度拆分与解耦、利用 `defineModel` 进行父子组件状态同步、单向数据流机制、通过 `Vue Devtools` 调试响应式流向。

## 板块三：Vue Router 路由管理

*   **3.1 路由初始化与配置**
    *   `createRouter` 创建路由实例
    *   `routes` 配置项（`path`, `name`, `component`, `meta`）
    *   路由懒加载（动态导入 `() => import(...)`）
*   **3.2 路由模式**
    *   HTML5 历史模式（`createWebHistory`，需后端路由重定向支持）
    *   Hash 模式（`createWebHashHistory`）
*   **3.3 路由导航**
    *   声明式导航（`<router-link>` 及其插槽用法）
    *   编程式导航（`useRouter`、`push`、`replace`、`go`）
*   **3.4 路由参数传递与接收**
    *   动态路径参数（`params`、`useRoute().params`）
    *   查询参数（`query`、`useRoute().query`）
    *   路由组件传参（`props: true` / 函数式配置简化数据接收）
*   **3.5 路由嵌套与多视图**
    *   嵌套路由（`children` 配置、`<router-view>` 嵌套）
    *   命名视图（同级展示多个 `<router-view>`，如侧边栏与主内容区）
*   **3.6 路由守卫**
    *   全局前置/后置守卫（`beforeEach`, `afterEach`）
    *   路由独享守卫（`beforeEnter`）
    *   组件内守卫（`onBeforeRouteLeave`, `onBeforeRouteUpdate`）

## 板块四：Pinia 状态管理与项目进阶

*   **4.1 Pinia 环境搭建**
    *   创建并注册 Pinia 根实例（`createPinia`）
*   **4.2 Store 的定义与定义风格**
    *   Options Store 风格（类似 Options API 的 `state`, `getters`, `actions`）
    *   Setup Store 风格（类似 Composition API，更易于组合逻辑复用）
*   **4.3 核心要素管理与轻量状态管理对比**
    *   State（共享状态的定义、修改与重置 `$reset`）
    *   Getters（状态派生、传参计算属性）
    *   Actions（同步方法与异步网络请求封装）
    *   *轻量替代方案*：基于 Composable 的简单响应式全局状态（无 Pinia 时的轻量状态共享）
*   **4.4 组件中的使用与响应式维护**
    *   直接解构带来的响应式丢失问题
    *   使用 `storeToRefs` 保持解构状态的响应式
*   **4.5 状态监控与持久化**
    *   `$patch` 批量修改状态
    *   `$subscribe` 监听状态变化
    *   Pinia 插件集成（如持久化插件 `pinia-plugin-persistedstate`）
*   🚩 **【阶段实战里程碑二：多页面交互应用】**
    *   **项目建议**：简易音乐播放器或个人事务工作台（Personal Dashboard）。
    *   **练习核心**：结合 Vue Router 搭建多页面应用，利用 Pinia 管理全局共享状态（如播放列表、用户配置、全局播放进度），使用 `storeToRefs` 保持解构响应式，并使用持久化插件储存用户数据。

## 板块五：高级特性与 TypeScript/工程化生态

*   **5.1 TypeScript 在 Vue 3 中的深度应用**
    *   项目初始化时的 TS 配置（`tsconfig.json`）
    *   为 Props, Emits 和 Ref 定义严格的 TS 类型
    *   为组件实例（Component Instance）与真实 HTML 元素标注 TS 类型
    *   *提示：在此阶段，建议尝试将之前里程碑一、二的代码进行重构，使其完全支持严格的 TS 类型检查。*
*   **5.2 组合式函数 (Composables)**
    *   逻辑复用的设计规范（如命名规范、输入参数响应式支持）
    *   有状态的组合式函数（如处理窗口大小 `useWindowSize`、网络请求 `useFetch` 等）
    *   资源销毁与副作用清理（在 Composable 中处理事件监听注销）
*   **5.3 内置组件与异步组件**
    *   `Teleport`（传送门，解决 DOM 层级限制问题，如 Modal/Toast）
    *   `KeepAlive`（页面/组件缓存，控制最大缓存实例数 `max`）
    *   `Suspense`（异步组件加载过渡）
    *   `Transition` & `TransitionGroup`（单元素与多元素过渡动画）
    *   **异步组件**（**`defineAsyncComponent`** 配合懒加载，实现非路由组件的按需加载）
*   **5.4 自定义指令 (Custom Directives)**
    *   指令对象的生命周期钩子
    *   局部注册与全局注册自定义指令（如 `v-lazy` 图片懒加载、`v-permission` 权限控制）
*   **5.5 Vite 构建工具与项目配置**
    *   配置文件 `vite.config.js` 的常用配置（别名设置 `@`、跨域代理 `proxy`、CSS 预处理器）
    *   单页面项目打包与生产环境优化（代码分包、Gzip 压缩等）
*   **5.6 Vue 3.5+ 全局辅助工具**
    *   **`useId`**（生成应用内唯一且稳定的 ID，主要用于无障碍开发 A11y 与 SSR）
