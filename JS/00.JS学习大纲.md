### 第一阶段：JavaScript 基础语法（入门）

这一阶段的目标是熟悉 JS 的基本语法，学会控制程序的逻辑流，并初步接触基本的数据存储结构。

1. **开发环境搭建**
   * 浏览器控制台（Console）的使用与基本调试指令（`console.log`）
   * 运行 JS 的方式（内联、内部、外部引入）
   * 常用编辑工具配置（如 VS Code 常用插件及配置，以及如何配置简单的断点调试环境）
2. **变量与数据类型**
   * 严格模式（`"use strict"`）的作用与使用场景
   * 变量声明：`let`、`const` 与旧有的 `var` 的区别及生存周期
   * 基础数据类型：`Number`、`String`、`Boolean`、`Null`、`Undefined`、`Symbol`、`BigInt`
   * 字符串进阶：模板字符串（Template Literals）及变量插值
   * 复杂数据类型基础：
     * `Object`（对象）的基本定义与属性读写
     * `Array`（数组）的基础声明、索引访问、`length` 属性及基础操作（`push`/`pop`/`shift`/`unshift`）
   * 解构赋值入门（基本的对象与数组解构，为后续获取事件对象或网络数据打下基础）
3. **运算符与表达式**
   * 算术运算符、赋值运算符、自增/自减
   * 比较运算符（特别注意 `==` 与 `===` 的区别）
   * 隐式类型转换机制、真值（Truthy）与假值（Falsy）的概念
   * 逻辑运算符（`&&`、`||`、`!`）及短路求值
4. **流程控制与错误处理基础**
   * 条件分支：`if-else`、`switch` 语句、三元运算符
   * 循环结构：`for`、`while`、`do-while`
   * 循环控制：`break`、`continue`
   * 异常捕获基础：`try...catch...finally` 与 `throw` 语句的基本用法
5. **函数基础**
   * 函数的声明与调用（Function Declaration）
   * 函数表达式（Function Expression）
   * **箭头函数基础语法（Arrow Function 极简形式，学习如何阅读和书写简写的函数回调）**
   * 参数（默认参数、剩余参数）与返回值

### 第二阶段：浏览器对象模型（DOM 与 BOM）

这一阶段将 HTML/CSS 与 JS 结合起来，实现网页的动态交互与基本的状态存储。

1. **DOM（文档对象模型）操作**
   * 获取 DOM 元素（`getElementById`、`querySelector`、`querySelectorAll`）
   * 修改元素内容与属性（`innerHTML`、`textContent`、`src`、`href` 等）
   * 特性（Attribute）与属性（Property）的区别（例如 `getAttribute('class')` 与 `.className`）
   * 修改样式（通过 `style` 属性或操作 `classList` 增删类名）
   * 动态创建、插入和删除节点（`createElement`、`appendChild`、`removeChild`）
2. **事件处理**
   * 常见事件类型（点击 `click`、键盘 `keydown`、鼠标移入移出、表单提交 `submit` 等）
   * 事件监听器（`addEventListener`）
   * 事件对象（`event`）的使用（阻止默认行为 `preventDefault`，阻止冒泡 `stopPropagation`）
   * 事件冒泡、事件捕获与事件委托（Event Delegation）
   * **高频事件的优化策略：防抖（Debounce）与节流（Throttle）的概念、应用场景及对比（此阶段着重于概念理解，具体代码实现放入第三阶段）**
3. **BOM（浏览器对象模型）**
   * `window` 对象的作用域
   * 定时器：`setTimeout` 与 `setInterval`
   * 页面路由/导航基础：`location` 与 `history` 对象
   * 浏览器本地存储：`localStorage` 与 `sessionStorage` 的增删改查
4. **🛠️ 阶段实战一：本地存储版待办事项（To-Do List）**
   * *项目目标*：通过该项目串联 DOM 的创建、删除、修改，绑定键盘与点击事件，并利用 `localStorage` 使得刷新页面后数据不丢失。

### 第三阶段：JS 核心特性进阶（掌握 JS 的灵魂）

这一阶段需要深入理解 JS 的运行机制、内存模型、闭包以及面向对象的设计思想。

1. **内存空间与复制原理**
   * 值类型（基本类型）与引用类型（对象类型）的区别
   * 内存模型：栈内存（Stack）与堆内存（Heap）
   * 浅拷贝（Shallow Copy）与深拷贝（Deep Copy）的区别
   * 深拷贝的实现方案：递归实现、`JSON` 序列化限制，以及现代原生 API `structuredClone()` 的使用
2. **作用域、垃圾回收与闭包**
   * 全局作用域、函数作用域与块级作用域（及变量提升现象）
   * 作用域链（Scope Chain）与词法作用域
   * JS 的垃圾回收（Garbage Collection）机制基础（引用计数与标记清除）
   * 闭包（Closure）的原理、内存泄漏风险及应用场景
   * **闭包实战：利用高阶函数手写实现防抖（Debounce）与节流（Throttle）函数**
3. **面向对象与 `this` 关键字**
   * `this` 的绑定规则（默认、隐式、显式 `call`/`apply`/`bind`、new 绑定）
   * 深入箭头函数（Arrow Functions）及其在 `this` 绑定上与普通函数的区别
   * 原型（Prototype）与原型链（Prototype Chain）
   * ES6 的 `class` 语法（类、构造函数、继承 `extends`、静态方法）
4. **常用内置对象及方法**
   * 数组常用高阶方法（`map`、`filter`、`reduce`、`forEach`、`some`、`every`、`find`）
   * 对象常用方法（`Object.keys`、`Object.values`、`Object.assign`）
   * 进阶解构赋值、展开运算符（Spread Operator）与剩余参数（Rest Parameters）
   * JSON 的解析与序列化（`JSON.parse`、`JSON.stringify`）
5. **浏览器调试技巧**
   * 如何利用 Sources/Debugger 面板进行单步断点调试、查看调用栈（Call Stack）与作用域变量（Scope）

### 第四阶段：异步编程与现代 JS（ES6+）

现代前端开发中，数据往往来自服务器，这需要扎实的异步编程知识与对运行机制的深刻理解。

1. **异步编程基础**
   * 同步与异步的概念
   * 回调函数（Callback）与回调地狱（Callback Hell）
2. **Promise（承诺）**
   * Promise 的三种状态（Pending、Fulfilled、Rejected）
   * Promise 链式调用（`.then()`、`.catch()`、`.finally()`）
   * Promise 常用静态方法（`Promise.all`、`Promise.race`、`Promise.allSettled`、`Promise.any`）
3. **Async / Await**
   * `async` 函数与 `await` 关键字的语法
   * 结合 `try...catch` 处理异步过程中的错误与异常
4. **JS 运行机制：事件循环（Event Loop）**
   * 认识执行栈（Execution Stack）与任务队列（Task Queue）
   * 宏任务（Macrotask）与微任务（Microtask）的执行顺序及区分
5. **现代 JS 模块化与网络请求**
   * 模块化规范，导出（`export`、`export default`）与导入（`import`）
   * AJAX 概念与 `fetch` API 的使用
   * **使用现代 URL 与 URLSearchParams API 构建和拼接网络请求参数（无需手动拼字符串）**
   * 请求中断与超时处理：`AbortController` 的引入与实战
6. **🛠️ 阶段实战二：天气预报查询应用**
   * *项目目标*：通过该项目练习如何发起 `fetch` 异步请求、处理异步响应、提取 JSON 数据并将其通过 DOM 动态渲染。结合 `try...catch` 进行断网、接口报错等异常边界处理，并尝试利用 `AbortController` 实现请求的取消。

### 第六阶段：TypeScript (TS) 进阶

TypeScript 是 JS 的超集，相当于给 JS 加上了“类型系统”。在现代前端开发中，TS 是极其关键的技能。

1. **TS 概念与开发环境搭建**
   * 为什么使用 TypeScript（静态类型检查在工程中的优势）
   * 安装 TS 编译器并在本地运行
   * 配置文件：`tsconfig.json` 的核心配置，特别注意 `"strict": true` 的重要性
2. **基本类型声明**
   * 基础类型：`string`、`number`、`boolean`、`null`、`undefined`
   * 特殊类型：`any`（类型逃生通道）、`unknown`（更安全的 any）、`void`、`never`
   * 数组与元组：`number[]`、`Array<string>`、`[string, number]`
3. **函数与对象的类型定义**
   * 函数参数与返回值的类型标注
   * 可选参数（`?`）与默认参数
   * 对象类型的声明
4. **接口（Interface）与类型别名（Type Alias）**
   * 接口的定义与继承（`extends`）
   * 类型别名的定义（`type`）
   * `interface` 与 `type` 的区别与选用建议
5. **高级类型系统与工具类型**
   * 联合类型（Union Types）与交叉类型（Intersection Types）
   * **类型收窄（Type Narrowing）与类型守卫（Type Guards，如 `typeof`、`instanceof`、字面量收窄，用于安全处理复杂类型）**
   * 类型断言（Type Assertion，如 `as string`）
   * 字面量类型与枚举（Enum）
   * 常用工具类型（Utility Types）：`Partial<T>`、`Required<T>`、`Readonly<T>`、`Pick<T, K>`、`Omit<T, K>`、`Record<K, T>`
6. **泛型（Generics）**
   * 泛型函数、泛型接口与泛型类
   * 泛型约束（`extends` 的用法）
7. **🛠️ 阶段实战三：用 TS 重构 To-Do List**
   * *项目目标*：将第二阶段写的 HTML/JS 项目转换为 TS 项目。定义数据模型接口（如 `interface TodoItem`），对 DOM 元素进行类型断言，体会强类型校验在防错、代码补全上的便利。
8. **TS 在现代框架中的应用（选学）**
   * 如何在 React 或 Vue3 项目中配置和使用 TS
