# Flex 布局全景指南

## 一、 基本概念
在开启 Flex 布局（`display: flex` 或 `display: inline-flex`）后，需要明确两个核心概念：
* **主轴（Main Axis）**：默认是水平方向，由 `flex-direction` 决定。
* **交叉轴（Cross Axis）**：与主轴垂直的方向，默认是垂直方向。
* *注意：当主轴方向改变时，所有的对齐属性（如 `justify-content` 和 `align-items`）指向的方向也会随之切换。*

---

## 二、 容器属性（设置在父元素上）

### 1. flex-direction（决定主轴的方向）
* **`row`（默认）**：水平方向，从左到右。
* **`column`**：垂直方向，从上到下。
* **`row-reverse`**：水平方向，从右到左。
* **`column-reverse`**：垂直方向，从下到上。

### 2. flex-wrap（决定是否换行）
* **`nowrap`（默认）**：不换行。如果子元素总宽度超出，会自动被挤压（受 `flex-shrink` 影响）。
* **`wrap`**：换行。一行装不下就换到下一行。
* **`wrap-reverse`**：换行，且颠倒行顺序（第一行在最下方）。

### 3. justify-content（主轴上的对齐方式）
* **`flex-start` / `start`（默认）**：紧贴主轴起点排列。
* **`flex-end` / `end`**：紧贴主轴终点排列。
* **`center`**：在主轴方向居中排列。
* **`space-between`**：首尾元素贴紧边界，其余元素均匀分布（中间间隔相等）。
* **`space-around`**：元素均匀分布，每个元素两侧的留白均等。因此，首尾元素与边界的距离是元素间距离的二分之一。
* **`space-evenly`**：元素均匀分布，首尾元素与边界的距离、元素之间的距离完全相等。

### 4. align-items（每一行内部在交叉轴上的对齐方式）
* **`stretch`（默认）**：如果子元素未设置高度（或高度为 `auto`），将占满整个父容器的高度（拉伸）。
* **`flex-start` / `start`**：对齐到交叉轴起点。
* **`flex-end` / `end`**：对齐到交叉轴终点。
* **`center`**：在交叉轴方向居中。
* **`baseline`**：以每个子元素内部第一行文字的基线对齐（非常适合图标与文字对齐）。

### 5. align-content（多行之间在交叉轴上的对齐方式）
*注意：该属性仅在设置了 `flex-wrap: wrap` 且出现多行时才生效。单行布局下无效。*
* **`stretch`（默认）**：各行平均分配并占满整个交叉轴空间。
* **`flex-start` / `start`**：所有行紧贴交叉轴起点排列。
* **`flex-end` / `end`**：所有行紧贴交叉轴终点排列。
* **`center`**：所有行在交叉轴中央紧凑排列。
* **`space-between`**：第一行与最后一行贴边，其余行均匀分布。
* **`space-around`**：每行两侧的留白均等。
* **`space-evenly`**：所有行均匀分布，行与行、行与边界的距离完全相等。

### 6. gap（设置元素之间的间距）
* 语法：`gap: [row-gap] [column-gap]` 
* 作用：直接设置子元素之间的网格间距，边缘元素不会产生多余的边距（比 `margin` 更好用）。

## 三、 项目属性（设置在每一个子元素上）

### 7. flex-grow（动态放大比例）
* **默认值：`0`**（即使有剩余空间，默认也不放大）。
* **数值作用**：当父容器有剩余空间时，子元素按比例分配并放大。数值越大，分到的剩余空间越多。
* 常用场景：配合 `max-width` 限制最大放大的尺寸。

### 8. flex-shrink（动态缩小比例）
* **默认值：`1`**（当父容器空间不足时，默认所有子元素都会等比例缩小以防溢出）。
* **`0`**：关闭缩小。即使空间不足，该元素也保持原有大小，不被挤压。
* **数值作用**：数值越大，在空间不足时缩小的速度越快（按比例分摊超出的空间）。
* 常用场景：配合 `min-width` 或设置 `flex-shrink: 0` 保证关键元素（如左侧图标、固定宽度的按钮）不被压扁。

### 9. flex-basis（计算伸缩前的基准大小）
* **默认值：`auto`**（如果子元素设置了 `width` / `height`，则采用该值；若没有设置，则由内容本身决定）。
* **数值作用**：可以设置具体的像素、百分比（例如 `200px`、`30%`），代表在分配剩余空间或收缩前，该项目本应占据的主轴空间。

### 10. flex（上述三者的简写属性，极力推荐使用）
在实际编码中，建议用 `flex` 简写来代替单独写三个属性。常见的预设值：
* **`flex: 1;`**（等同于 `flex: 1 1 0%;`）：子元素自动平分剩余空间，且宽度完全一致。
* **`flex: auto;`**（等同于 `flex: 1 1 auto;`）：子元素会自动分配空间，但会优先考虑自身内容的大小。
* **`flex: none;`**（等同于 `flex: 0 0 auto;`）：固定大小，既不放大也不缩小（非常适合固定宽度的侧边栏）。

### 11. align-self（单个元素在交叉轴上的对齐方式）
* 允许单个子元素覆盖父容器的 `align-items` 设置。
* **`auto`（默认）**：继承父元素的 `align-items` 属性。
* **`flex-start`**：对齐到交叉轴起点。
* **`flex-end`**：对齐到交叉轴终点。
* **`center`**：在交叉轴方向居中。
* **`stretch`**：拉伸占满。

### 12. order（改变子元素的排列顺序）
* **默认值：`0`**。
* **数值作用**：数值越小，排列越靠前（可以为负数，如 `-1`）。常用于响应式设计中，改变手机端和 PC 端的视觉排版顺序，而不必改动 HTML 结构。

## 四、 避坑指南与经典技巧

### 1. 为什么没有 `justify-self`？如何实现非对称对齐？
* Flexbox 规范中**没有** `justify-self` 属性。
* **解决方案**：利用 **`margin-auto`**。
  * 如果希望一行元素中，左侧放一个 Logo，右侧放其余导航，只需在左侧 Logo 元素上设置：`margin-right: auto;` 即可。
  * 同样，在 Flex 容器中，对子元素使用 `margin: auto;` 可以非常优雅地实现水平和垂直双重居中。

### 2. 经典踩坑：子元素内的文字或长内容溢出，且不自动换行/省略
* **问题现象**：当子元素内部含有长英文字符、大图或设置了不换行的文本（`white-space: nowrap`）时，即使设置了 `flex-shrink: 1` 或 `flex: 1`，该子元素也无法缩小，甚至会把父容器撑开。
* **原因分析**：Flex 项目的默认最小尺寸是 `min-width: auto`（或 `min-height: auto`），它会强行撑起元素。
* **解决方案**：在被撑开的子元素上，手动设置 **`min-width: 0;`**（或如果是垂直方向设置 `min-height: 0;`），这样就能打破默认限制，使 `flex-shrink` 以及文字省略号（`text-overflow: ellipsis`）正常生效。
