# grid 布局

1. grid-template-columns：定义多少列

   - 30px 50px 60px 代表有三列分别为30 50 60 px宽
   - 1fr 3fr 5fr 代表按照1：3：5的宽度分成3列
   - fr 和 px 可以混用
   - 使用minmax(a, b) 表示该列最小宽度是a, 最大宽度是b, 可以混用 fr 和px
   - 用 repeat(n, 150px), 表示创建 n 列宽度为150的列

2. grid-template-rows：定义多少行

   - 和列同理

3. 可以用 gap 来设置元素之间的距离，如果是两个值，那么第一个是行之间的间距，第二个是列之间的间距

4. 确定一个元素占用的空间（以下为2行3列）

   - grid-row-start: 1; 行起点
   - grid-row-end: 3; 行终点
   - grid-column-start: 1; 列起点
   - grid-column-end: 4; 列终点
   - 上述简写
     - grid-row: 1 / 3;
     - grid-column: 1 / 4；
     - 此种写法用负数表示倒数第几条线，-1表示倒数第一条线
     - 若发生堆叠，可以使用z-index来设置堆叠顺序
   - span: 不关心起始位置，只关心占据了多少行多少列（以下为3行4列）
     - grid-row: span 3;
     - grid-column: span 4；

5. grid-template-areas

   ```css
   .container {
           display: grid;
           grid-template-columns: 1fr 3fr;
           grid-template-rows: 100px 300px 100px;
           grid-template-areas:
             "header header"
             "aside main"
             "footer footer";
         }
   
   
         .item-1 {
           grid-area: header;
         }
   
         .item-2 {
           grid-area: aside;
         }
   
         .item-3 {
           grid-area: main;
         }
         
         .item-4 {
           grid-area: footer;
         }
   ```

   每一个双引号代表一行；一行里面有几个名称代表有几列；每一个名称代表一个网格单元；多个相同名称组成的区域是网格区域，如果希望某个单元格为空，只需名称用`.`代替即可

6. 隐式网格

   - 当网格已经被占满，此时如果往网格容器里面新增元素，新被渲染出来的网格叫做隐式网格，默认是行

     ```css
     .container {
             display: grid;
             grid-template-columns: 1fr 3fr;
             grid-template-rows: 100px 300px 100px;
             grid-template-areas:
               "header header"
               "aside main"
               "footer footer";
             /* 设置之后变为列 */
             grid-auto-flow: column;
             /* 列宽 */
             grid-auto-columns: 100px;
           }
     ```

     ```css
     .container {
             display: grid;
             grid-template-columns: 1fr 3fr;
             grid-template-rows: 100px 300px 100px;
             grid-template-areas:
               "header header"
               "aside main"
               "footer footer";
             /* 默认是行 */
             grid-auto-flow: row;
             /* 行高 */
             grid-auto-columns: 100px;
           }
     ```
